[0.1.0] - 2026-11-11

首个可用版本：ETL → ODS → DWD → DWS → ADS → BI 全链路打通。

Added

接入 - PostgreSQL / MySQL / ClickHouse 连接器，Capability 能力矩阵 - 元数据采集：schema → table → columns，逐表失败隔离 - 数据源凭证 AES-256-GCM 加密存储，接口不回传明文

建模 - YAML 模型定义 → 校验 → DDL 编译（4 方言） - 版本化发布，发布版本不可变，支持回滚 - 表、列、分区、唯一键、质量的完整校验，问题一次性收集

管道 - 严格 YAML 解析，成环/依赖/参数/节点字段校验 - 7 类节点：source / sql / quality / sink / shell / http / branch - 4 种写入策略：append / overwrite / upsert / overwrite_partition - 有 Transactor 的引擎包事务，失败整体回滚 - SQL 模板 ${var} 渲染，值按字面量转义，杜绝注入

调度 - 5 段 cron，T-1 派发，重启补偿窗口 - 幂等键（schedule/backfill 为 pipeline_id:biz_date） - SKIP LOCKED 领取 + 租约心跳 + 僵尸回收 - 补数 CLI，按日期区间批量建实例

质量与血缘 - 6 类规则：not_null / unique / accepted_values / range / row_count / custom - error 级门禁阻断下游，warn 只记录 - 表级血缘（depends_on）+ 列级血缘（SQL 解析） - 影响分析：从某列向下追溯所有受影响的下游列

语义层 - 指标定义（聚合白名单 + 维度校验），不开放任意 SQL - 时间序列查询，按天/周/月聚合，支持维度拆分 - 多指标看板，span 控制布局 - 指标结果缓存，实例结束后自动失效

治理 - JWT 登录 + RBAC（admin/editor/viewer） - 列级脱敏（partial/hash/email/phone/full）与数据分级 - 行级权限，支持 ${user} / ${role} 占位符 - 审计日志，写操作全留痕 - 多租户：工作区隔离、成员管理、工作区切换 - 公开分享链接，可设过期时间

交付 - 单二进制 + go:embed 内嵌控制台，10 个页面 - CLI：migrate / doctor / apply / run / seed / backfill / lineage / profile / export / lint - 管道可视化编排：拖拽、连线、双击编辑，保存即写回 YAML - Docker Compose、多阶段镜像、Helm Chart - GitHub Actions：lint / test / build / e2e - Prometheus /metrics，手写导出器无额外依赖 - 文档站生成脚本（scripts/build_docs.py）

设计取舍

项 选择 理由
调度中间件 不引入 Kafka/Temporal PG 的 SKIP LOCKED + 租约，少一个组件
SQL 访问层 pgx 手写 SQL 血缘递归、实例分页用生成器反而难维护
前端 原生 JS + go:embed 单二进制可用，无 npm 构建链
指标表达式 只允许列名 + 聚合白名单 指标是业务口径，不该成为注入面
日志 log/slog 标准库够用，少一个依赖
指标导出 手写 Prometheus 文本格式 指标集小，不值得引入 client_golang
