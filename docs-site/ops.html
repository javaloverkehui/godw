频率 检查项 命令 / 位置

2. 常见故障

2.1 实例卡在 running

现象：status=running 超过 lease_sec 仍未结束。

原因：worker 进程被杀，租约过期。

处理：调度器每分钟会自动 Recover，把过期租约退回 queued。若需立即恢复：

UPDATE instance SET status='queued', worker_owner='', lease_until=NULL
WHERE status='running' AND lease_until < now();

2.2 管道反复失败

按这个顺序排查：

  1. 看实例详情里的 error 字段，通常带节点 ID 与 SQL。
  2. curl /api/v1/instances/{id} 看 tasks 里哪个节点失败。
  3. 质量门禁（CodeQualityGate=40004）说明数据本身不达标，不是代码问题。
  4. 连续失败 3 次会被标 blocked，依赖它的下游自动跳过 —— 修好后手动触发一次即可解除。

2.3 数据源连不上

godw-cli doctor --config config.yaml

会逐项检查配置、DB、各数据源连通性与 schema 版本。连不上通常三类原因：

  • 网络策略（PG 的 pg_hba.conf 未放行 Pod CIDR）
  • 密码过期（GODW_DB_PASSWORD 与库里不一致）
  • SSL 模式不匹配（ssl_mode=require 但服务端未开 TLS）

2.4 控制台白屏

内嵌前端是单文件 JS，出问题多半是接口 500。打开 DevTools 看第一个红叉：

  • /api/v1/me 401 → token 过期，重新登录
  • /api/v1/overview 500 → 查服务日志 grep '"status":500'
  • /assets/app.js 404 → 二进制构建时漏了 go:embed，重新 go build

3. 备份与恢复

备份

# 元数据（必须）：体积小，每天全量
pg_dump -Fc godw > backup/godw-$(date +%F).dump

# 业务数据：由各数据源自身的备份策略负责，本系统不复制数据

恢复

pg_restore -d godw --clean --if-exists backup/godw-2026-11-11.dump
godw-cli migrate --config config.yaml   # 补齐可能落后的 schema

注意：恢复后 instance 里 running 的记录是脏状态，执行一次上面的回收 SQL。

4. 升级

# 1. 备份
pg_dump -Fc godw > backup/pre-upgrade.dump

# 2. 拉新版本，先跑迁移（向前兼容，不删列）
godw-cli migrate --config config.yaml

# 3. 滚动重启 worker（它们会先把当前实例跑完）
kubectl rollout restart deploy/godw-worker

# 4. 再重启 server
kubectl rollout restart deploy/godw-server

兼容性承诺：迁移只做加法（加表、加列、加索引）。删列/改类型会单独发大版本，并在 CHANGELOG 标注。

5. 扩缩容

加 worker

kubectl scale deploy/godw-worker --replicas=6

无需改配置：worker 通过 SKIP LOCKED 竞争领取，加副本即加吞吐。

加 server

server 带调度器，多副本会重复扫描 cron。当前实现靠幂等键保证不重复建实例，但会浪费扫描。推荐只跑 1 个调度实例，把 HTTP 与调度拆开部署时：

# 只跑 HTTP，不跑调度
scheduler:
  enabled: false

6. 观测

端点 用途
/healthz 存活探针，只证明进程活着
/readyz 就绪探针，检查 DB 可达
/metrics Prometheus 文本格式

已有指标：

godw_http_requests_total{method,route,status}
godw_http_request_duration_seconds_bucket{le}
godw_uptime_seconds

推荐告警规则：

- alert: GoDWHighErrorRate
  expr: sum(rate(godw_http_requests_total{status=~"5.."}[5m]))
        / sum(rate(godw_http_requests_total[5m])) > 0.02
  for: 10m
- alert: GoDWSlowRequests
  expr: histogram_quantile(0.99, sum(rate(godw_http_request_duration_seconds_bucket[5m])) by (le)) > 2
  for: 10m

7. 日志

JSON 格式（log.format=json）关键字段：

字段 含义
ts 时间
level 级别
msg http 表示访问日志，其余为业务事件
request_id 贯穿一次请求，响应头 X-Request-Id 同值
path / status / ms 访问日志三件套

按 request_id 串起来看：

jq -c 'select(.request_id=="01M7...")' server.log

8. 安全清单

  • [ ] auth.jwt_secret 不是默认值，长度 ≥ 32
  • [ ] auth.bootstrap_pass 首次登录后改掉，或干脆不配
  • [ ] 数据库不对公网开放
  • [ ] /metrics 与 /healthz 在网关层限制来源
  • [ ] 数据源凭证确认是加密存储（datasource.secret_enc 非空）
  • [ ] 列策略已覆盖手机号、身份证、邮箱等敏感列
  • [ ] 审计日志保留 ≥ 180 天
