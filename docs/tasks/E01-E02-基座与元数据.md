#### T0102 · 配置系统  `P0` `1d`
**目标**：一份配置跑多环境，敏感信息不落盘。
**要点**
- `config.yaml` + 环境变量覆盖，前缀 `GODW_`，层级用 `_` 连接（`GODW_DB_HOST`）。
- 结构体用 `validator` 标签做必填/范围校验，启动失败要打印**具体字段名**和来源。
- 支持 `config.dev.yaml` / `config.prod.yaml` 叠加；`--config` 指定路径。
- 敏感项只允许从环境变量或 secret 文件读，禁止写默认值。
**产出**：`internal/config/config.go`、`loader.go`、`config.example.yaml`。
**验收**：三条优先级（默认 < 文件 < 环境变量）单测通过；缺 `db.host` 时启动报 `config: db.host is required (source: default)`。

#### T0103 · 日志、错误码与链路 ID  `P0` `1d`
**目标**：出问题能凭一个 ID 定位全链路。
**要点**
- zap JSON 输出，固定字段 `ts/level/msg/request_id/trace_id/workspace_id/instance_id`。
- `pkg/errs` 定义 `AppError{Code int, Msg string, Cause error, Meta map[string]any}`，实现 `Unwrap()`；提供 `Wrap/Is/As`。
- 错误码常量集中在 `pkg/errs/codes.go`，分段与 API 文档一致（10xxx/20xxx/30xxx/40xxx/50xxx）。
- HTTP 中间件生成 `request_id`（ULID），注入 ctx 与响应头 `X-Request-Id`；panic 恢复为 500 并记录堆栈。
**产出**：`pkg/errs/*`、`internal/obs/log/*`、中间件。
**验收**：构造 3 层包装错误，`errors.Is` 能命中底层；panic 请求返回统一 JSON 且日志含 stack。

#### T0105 · HTTP 基础层  `P0` `1.5d`
**目标**：所有接口共享一致的入参校验、响应与错误处理。
**要点**

- 统一响应封装 `{code,message,data,requestId}`；分页解析 `page/pageSize/sort`，`pageSize` 上限 200。

**产出**：`internal/api/http/router.go`、`middleware/*`、`response/*`。
**验收**：非法 body 返回 400 + 字段名；`/readyz` 在 DB 断开时返回 503；中间件顺序有单测。

#### T0202 · Repository 层  `P0` `2d`
**目标**：数据访问集中、可控、可测。
**要点**
- 每个聚合一个 repo（`ModelRepo/PipelineRepo/InstanceRepo/...`），方法首参 `ctx`。

**产出**：`internal/meta/repo/*.go`、`tx.go`。
**验收**：并发更新同一模型，一个成功一个 409；repo 测试跑真 PG 且覆盖软删除过滤。

#### T0203 · 工作空间与环境  `P0` `1d`

#### T0204 · 数据源管理  `P0` `2d`
**目标**：安全地存连接信息并验证可用性。
**要点**
- 密码走 `secret` 表：AES-256-GCM，密钥来自环境变量 `GODW_SECRET_KEY`（32 字节），支持 `key_version` 轮换。
- 连接串按类型拼装，参数集中在 `connector/dsn.go`，禁止字符串拼接 SQL。
- 测试连接超时 5s，返回耗时与版本号；失败区分「网络不可达 / 认证失败 / 库不存在」。
- 列表接口不回传密码，只回 `hasPassword: true`。
**产出**：`internal/meta/service/datasource.go`、`internal/connector/dsn.go`、加密工具。
**验收**：DB 中 `secret` 表无明文；错误密码返回 `50002 auth failed`；测试接口 5s 内必返回。

#### T0205 · 连接器接口与注册表  `P0` `2d`

#### T0206 · 四个首期连接器  `P0` `4d`
**目标**：覆盖 80% 使用场景。
**要点**
- PostgreSQL（pgx）、MySQL（go-sql-driver）、ClickHouse（clickhouse-go v2）、DuckDB（嵌入式）。
- 每个实现 `Capabilities()`：PG/MySQL `MergeUpsert=true`；Doris `InsertOverwrite=true`；ClickHouse `InsertOverwrite=false, ReplacePartition=true`（CH 无 `INSERT OVERWRITE`，只有 `REPLACE PARTITION`）；DuckDB 单机全支持。能力声明错一个，写入策略就会生成跑不通的 SQL，必须有集成测试兜底。
- 类型映射表落在 `dialect/<engine>/types.go`，覆盖 string/int/float/decimal/date/timestamp/bool/json/array。
- 大结果集用 `Stream`，CH 必须用 native 协议而非 HTTP。
**产出**：`connector/{postgres,mysql,clickhouse,duckdb}/*`。
**验收**：`connectortest` 全通过；10 万行导出内存增长 < 100MB；`Cancel` 后服务端查询确实终止（查 `pg_stat_activity` / `system.processes`）。

#### T0207 · 元数据采集  `P0` `2d`
**目标**：不连库也能看到表结构。
**要点**
- 统一 `Collector` 接口：`Collect(ctx, schema) ([]TableMeta, error)`，各引擎用 `information_schema` / `system.tables` / `DESCRIBE`。
- 计算结构指纹 `fingerprint = sha256(sorted(column name+type+nullable))`，与库中比对判断是否变化。
- 大表行数用估算（`pg_class.reltuples`、`system.parts`），不做 `COUNT(*)`。
- 采集结果写 `meta_table`，保留上次指纹用于变更对比。
**产出**：`connector/*/collect.go`、`internal/meta/service/collect.go`。
**验收**：1000 张表采集 ≤ 30s；新增一列后再次采集能识别 `add_column`。

#### T0208 · 采集调度与变更告警  `P1` `1.5d`
**目标**：表结构漂移能被发现。
**要点**
- 支持手动刷新与定时刷新（默认每日 02:00），同一数据源加分布式锁防并发。
- 采集 diff 生成 `schema_change` 记录（add/drop/modify column），推送到站内消息。
- 采集失败重试 3 次，仍失败标记数据源 `status=failed` 并告警。
**产出**：`internal/meta/service/collect_job.go`、变更记录表与 API。
**验收**：删除源表一列后，站内消息出现 `drop_column` 且含表名与列名。

#### T0209 · 敏感字段识别  `P1` `1.5d`
**目标**：为脱敏与合规提供依据。
**要点**
- 规则两层：列名正则（`phone|mobile|id_card|email|bank_card|address`）+ 值采样（每列最多 200 行，正则命中率 > 80% 判定）。
- 采样必须 `LIMIT`，禁止全表扫描；对超大表随机采样。
- 结果写 `column.pii`（none/low/medium/high）与 `pii_reason`，允许人工覆盖并记录操作人。
**产出**：`internal/meta/service/pii.go`、识别规则配置。
**验收**：样例库中手机号/邮箱列识别准确率 ≥ 90%；人工修改后不被下次采集覆盖。

#### T0210 · 元数据搜索与标签  `P1` `1.5d`
**目标**：几万张表里能快速找到目标表。
**要点**
- PG 全文检索（`to_tsvector('simple', name||comment)`）+ `pg_trgm` 模糊匹配双通道，中文按字切分。
- 支持按 `layer/datasource/tag/owner` 过滤，结果高亮命中词。
- 标签 CRUD + 批量打标；标签可作为模型编译的软约束（如 `pii=high` 必须有脱敏）。
**产出**：搜索 API、标签表与 service。
**验收**：10 万行元数据下关键词搜索 p95 ≤ 100ms；中文表名可命中。
