# 02 · 元数据模型

所有对象以 `workspace_id` 为隔离边界；所有写操作带 `created_by / updated_by / updated_at`；软删除统一用 `deleted_at TIMESTAMPTZ NULL`。

## 1. ER 关系

```
workspace 1─n env 1─n datasource 1─n meta_table
workspace 1─n model 1─n model_column
                 └─1─n model_version
workspace 1─n pipeline 1─n pipeline_node
                    │        └─1─n pipeline_edge
                    └─1─n pipeline_version
pipeline_node 1─n task_instance 1─n run 1─n run_log(分区)
model 1─n quality_rule 1─n quality_result
model 1─n lineage_edge(表/列级)
workspace 1─n dataset 1─n metric
workspace 1─n dashboard 1─n chart
user n─n role n─n permission
```

## 2. 核心表 DDL（节选，实际迁移脚本以此为准）

### 2.1 工作空间与环境

```sql
CREATE TABLE workspace (
  id           BIGSERIAL PRIMARY KEY,
  slug         TEXT NOT NULL UNIQUE,
  name         TEXT NOT NULL,
  description  TEXT NOT NULL DEFAULT '',
  settings     JSONB NOT NULL DEFAULT '{}',   -- 全局变量、默认时区、配额
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  deleted_at   TIMESTAMPTZ
);

CREATE TABLE env (
  id           BIGSERIAL PRIMARY KEY,
  workspace_id BIGINT NOT NULL REFERENCES workspace(id),
  name         TEXT NOT NULL,                 -- dev / staging / prod
  kind         TEXT NOT NULL CHECK (kind IN ('dev','staging','prod')),
  is_default   BOOLEAN NOT NULL DEFAULT false,
  bindings     JSONB NOT NULL DEFAULT '{}',   -- datasource 别名 -> datasource_id
  UNIQUE (workspace_id, name)
);
```

> `bindings` 是「模型写 `datasource: ch_main`，dev 环境映射到 ds_id=3，prod 映射到 ds_id=7」的实现方式。模型定义做到环境无关。

### 2.2 数据源

```sql
CREATE TABLE datasource (
  id            BIGSERIAL PRIMARY KEY,
  workspace_id  BIGINT NOT NULL REFERENCES workspace(id),
  name          TEXT NOT NULL,
  type          TEXT NOT NULL,          -- postgres|mysql|clickhouse|doris|duckdb|hive|s3
  host          TEXT NOT NULL DEFAULT '',
  port          INT  NOT NULL DEFAULT 0,
  database_name TEXT NOT NULL DEFAULT '',
  username      TEXT NOT NULL DEFAULT '',
  secret_id     BIGINT REFERENCES secret(id),   -- 密码不落本表
  props         JSONB NOT NULL DEFAULT '{}',    -- 连接参数（ssl、超时、catalog）
  status        TEXT NOT NULL DEFAULT 'unknown',-- unknown|ok|failed
  last_check_at TIMESTAMPTZ,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (workspace_id, name)
);

CREATE TABLE secret (
  id           BIGSERIAL PRIMARY KEY,
  workspace_id BIGINT NOT NULL,
  name         TEXT NOT NULL,
  cipher_text  BYTEA NOT NULL,        -- AES-256-GCM(明文)
  nonce        BYTEA NOT NULL,
  key_version  INT NOT NULL DEFAULT 1,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### 2.3 元数据采集结果

```sql
CREATE TABLE meta_table (
  id            BIGSERIAL PRIMARY KEY,
  datasource_id BIGINT NOT NULL REFERENCES datasource(id),
  schema_name   TEXT NOT NULL,
  table_name    TEXT NOT NULL,
  table_type    TEXT NOT NULL,          -- table|view|mv|external
  comment       TEXT NOT NULL DEFAULT '',
  row_count     BIGINT,
  size_bytes    BIGINT,
  columns       JSONB NOT NULL,         -- [{name,type,nullable,default,comment,ordinal,pii}]
  partition_keys TEXT[] NOT NULL DEFAULT '{}',
  engine_props  JSONB NOT NULL DEFAULT '{}',
  fingerprint   TEXT NOT NULL,          -- 结构指纹，用于变更检测
  synced_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (datasource_id, schema_name, table_name)
);
CREATE INDEX idx_meta_table_search ON meta_table USING gin (to_tsvector('simple', table_name || ' ' || comment));
```

### 2.4 模型

```sql
CREATE TABLE model (
  id            BIGSERIAL PRIMARY KEY,
  workspace_id  BIGINT NOT NULL,
  layer         TEXT NOT NULL CHECK (layer IN ('ods','dwd','dws','ads')),
  name          TEXT NOT NULL,              -- 必带层前缀，如 dwd_order_detail
  display_name  TEXT NOT NULL DEFAULT '',
  description   TEXT NOT NULL DEFAULT '',
  datasource_alias TEXT NOT NULL,           -- 逻辑别名，经 env.binding 解析
  materialization TEXT NOT NULL CHECK (materialization IN ('table','view','mv','incremental')),
  storage       JSONB NOT NULL DEFAULT '{}',-- {format,partition_by,order_by,bucket,ttl}
  schema_json   JSONB NOT NULL,             -- 列定义（权威来源）
  status        TEXT NOT NULL DEFAULT 'draft', -- draft|published|deprecated
  current_version INT NOT NULL DEFAULT 0,
  owner         TEXT NOT NULL DEFAULT '',
  tags          TEXT[] NOT NULL DEFAULT '{}',
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (workspace_id, name)
);

CREATE TABLE model_version (
  id          BIGSERIAL PRIMARY KEY,
  model_id    BIGINT NOT NULL REFERENCES model(id),
  version     INT NOT NULL,
  snapshot    JSONB NOT NULL,        -- 完整模型定义（不可变）
  ddl         TEXT NOT NULL,         -- 编译产物
  ddl_hash    TEXT NOT NULL,
  change_note TEXT NOT NULL DEFAULT '',
  published_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (model_id, version)
);
```

### 2.5 管道

```sql
CREATE TABLE pipeline (
  id           BIGSERIAL PRIMARY KEY,
  workspace_id BIGINT NOT NULL,
  name         TEXT NOT NULL,
  description  TEXT NOT NULL DEFAULT '',
  schedule     JSONB NOT NULL DEFAULT '{}', -- {cron,timezone,start_date,end_date,max_concurrency}
  params       JSONB NOT NULL DEFAULT '[]', -- [{name,type,default,required}]
  resources    JSONB NOT NULL DEFAULT '{}', -- {group,etl_timeout,retry:{max,backoff}}
  status       TEXT NOT NULL DEFAULT 'draft',
  current_version INT NOT NULL DEFAULT 0,
  UNIQUE (workspace_id, name)
);

CREATE TABLE pipeline_version (
  id          BIGSERIAL PRIMARY KEY,
  pipeline_id BIGINT NOT NULL REFERENCES pipeline(id),
  version     INT NOT NULL,
  graph       JSONB NOT NULL,     -- {nodes:[...], edges:[...]} 快照
  compiled    JSONB NOT NULL,     -- 编译结果：拓扑序、参数依赖、血缘边
  published_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (pipeline_id, version)
);
```

> 节点/边同时落 `pipeline_node` / `pipeline_edge` 便于查询（「哪些管道用了这张表」），但**运行时以 `pipeline_version.graph` 快照为准**。

### 2.6 实例与运行（分区表）

```sql
CREATE TABLE task_instance (
  id           BIGSERIAL,
  workspace_id BIGINT NOT NULL,
  pipeline_id  BIGINT NOT NULL,
  version_id   BIGINT NOT NULL,
  node_key     TEXT NOT NULL,
  biz_date     DATE NOT NULL,
  state        TEXT NOT NULL,   -- PENDING|READY|QUEUED|RUNNING|SUCCESS|FAILED|KILLED|SKIPPED|UPSTREAM_FAILED|RETRY_WAIT
  priority     INT NOT NULL DEFAULT 5,
  attempt      INT NOT NULL DEFAULT 0,
  max_attempt  INT NOT NULL DEFAULT 3,
  resource_group TEXT NOT NULL DEFAULT 'default',
  worker_id    TEXT,
  lease_until  TIMESTAMPTZ,
  scheduled_at TIMESTAMPTZ NOT NULL,
  started_at   TIMESTAMPTZ,
  finished_at  TIMESTAMPTZ,
  error_code   TEXT,
  error_msg    TEXT,
  rendered_sql TEXT,             -- 渲染快照（重跑复用）
  params_snapshot JSONB,         -- 参数快照
  metrics      JSONB,            -- {rows_read,rows_written,bytes,duration_ms}
  PRIMARY KEY (id, biz_date)
) PARTITION BY RANGE (biz_date);

CREATE UNIQUE INDEX uq_instance ON task_instance (pipeline_id, node_key, biz_date);
CREATE INDEX idx_instance_queue ON task_instance (state, priority, scheduled_at)
  WHERE state IN ('READY','QUEUED');
```

**幂等键 = (pipeline_id, node_key, biz_date)**。唯一索引保证「重复触发不产生重复实例」，这是补数安全的基础。

```sql
CREATE TABLE run (
  id          BIGSERIAL PRIMARY KEY,
  instance_id BIGINT NOT NULL,
  biz_date    DATE NOT NULL,
  engine      TEXT NOT NULL,
  sql_hash    TEXT NOT NULL,
  rows_read   BIGINT DEFAULT 0,
  rows_written BIGINT DEFAULT 0,
  bytes_scanned BIGINT DEFAULT 0,
  duration_ms INT DEFAULT 0,
  log_uri     TEXT,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE run_log (
  id BIGSERIAL,
  run_id BIGINT NOT NULL,
  seq INT NOT NULL,
  ts TIMESTAMPTZ NOT NULL DEFAULT now(),
  level TEXT NOT NULL,
  message TEXT NOT NULL,
  PRIMARY KEY (id, ts)
) PARTITION BY RANGE (ts);
```

## 3. 状态机

### 3.1 任务实例

```
        ┌──────────┐  上游全部 SUCCESS   ┌───────┐  资源组有空位  ┌────────┐
新建 ──▶│ PENDING  │────────────────────▶│ READY │───────────────▶│ QUEUED │
        └──────────┘                     └───────┘                └───┬────┘
             │ 上游失败                      │ 手动跳过                 │ worker 租约领取
             ▼                              ▼                         ▼
      UPSTREAM_FAILED                   SKIPPED                   RUNNING
                                                                     │
                        ┌────────────────────────────────────────────┼────────────┐
                        │ 成功                                       │ 失败        │ 被 kill
                        ▼                                            ▼            ▼
                     SUCCESS                                    RETRY_WAIT      KILLED
                                                                     │ 达上限
                                                                     ▼
                                                                  FAILED
```

**合法迁移必须用条件更新**：`UPDATE task_instance SET state=$new WHERE id=$id AND state=$expected`，受影响行数为 0 说明并发冲突，直接放弃本次迁移。禁止「先查后改」。

### 3.2 管道版本

`draft → published → deprecated`。只有 `published` 可被调度；`draft` 可任意编辑；`deprecated` 保留历史实例可查。

## 4. 幂等与重跑规则

1. **实例唯一**：`(pipeline_id, node_key, biz_date)` 唯一索引，重复触发直接返回已存在实例。
2. **写入幂等**：目标表必有 `dt`（业务日期）与 `_godw_run_id`；`overwrite_partition` 先删分区再插，`merge` 按主键 upsert。
3. **渲染快照**：首次执行时把渲染后的 SQL 和参数写入 `task_instance`；重跑默认复用快照，除非显式勾选「重新渲染」。
4. **重跑不改历史**：每次执行新增 `run` 记录，`task_instance.attempt++`，旧 run 保留可追溯。
5. **补数并行**：按 biz_date 展开实例，同一管道内按 DAG 层级并行，跨日期按 `max_concurrency` 限流。

## 5. 索引与容量

| 表 | 增长量级 | 策略 |
|---|---|---|
| `task_instance` | 万/日 | 按月分区，保留 6 个月，超期归档到对象存储 |
| `run` | 万/日 | 与实例同生命周期，索引 `(instance_id)`、`(created_at)` |
| `run_log` | 百万行/日 | 按日分区，仅保留 7 天在库，其余压缩归档 |
| `lineage_edge` | 十万级 | 全量保留，按 `src_table/dst_table` 建索引 |
| `quality_result` | 万/日 | 按月分区，保留 1 年 |

分区维护由一个内置的 `maintenance` 定时任务完成：提前 7 天创建下月分区、删除过期分区、触发归档。
