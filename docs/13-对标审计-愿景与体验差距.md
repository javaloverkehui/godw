# 13 · 对标审计：「不是再造一个 Airflow」的愿景达成度（含交互与设计）

> 审计时间：2026-11-14（首轮）+ 同日补齐后复测（v1.1.0 / v1.2.0）  
> 审计方式：起真实服务（PostgreSQL + 内嵌调度）+ 逐页操作 + 读码核对 + headless 回归  
> 审计对象：README §1 的对标表、§0.1 的能力表、`docs/tasks/E09-E10` 的前端验收标准  
> 结论一句话：**后端 ≈ 4.1/5；前端从 2.5 补到 ≈ 4.1——差距不再是「没做完」，而是规模化与专业化（500 节点、SQL 控制台、docs 站）。**

---

## 2. 结论：三句话

1. **「不重复造 Airflow」这个定位成立。** 建模 DSL、分层强约束、写入策略、质量门禁、列级血缘、语义层这套组合，Airflow/Dagster/dbt/DS 单拎任何一个都拿不出来，四合一确实是空位。
2. **但「值得借鉴」的那部分，多数只借鉴了后端，没借鉴交互。** Airflow 的 Graph/Grid、Dagster 的资产视图、dbt 的 docs、DS 的画布、Metabase 的图表交互，共同特征&#x662F;**「运行态一眼可见、任何对象三次点击内到细节」**——这正是首轮最弱的一环，现已补齐大半。
3. **最大的风险不是功能缺，是「完成了」的定义被放宽了。** `runner/tasks.json` 记 T0905/T0906/T0907 完成，但 T0905 明文要求缩放/框选/小地图/撤销重做/节点状态呼吸灯/SSE 日志抽屉，首轮实测一条都没有。**补齐后这条风险依然存在**：任务卡写「完成」时，仍应以本文 §6 的可执行断言为准。

## 2.3 第三批：对 §4 十五条的独立复核（2026-11-14，v1.3.0）

不引用上文结论，重新起服务、逐条读码 + headless 断言，重跑一遍。**结论：15 条里有 14 条真的能用；
P0-1 只算「大部分成立」——撤销对拖动无效、方向键微调静默丢失、对齐辅助线缺失，而这三项都写在 T0905 的验收里。**
另外查出一个文档没记的结构性问题：`#/runbook`（甘特/补数/批量所在页）侧栏没有入口，等于功能写了但用不到。

本轮修掉的 5 处（都已用脚本复验）：

| 问题 | 根因 | 修法 | 复验 |
|---|---|---|---|
| 拖动节点后 `Ctrl+Z` 什么都不做 | 快照在 `mouseup` 才取，此时坐标已经改完，撤销栈里存的是「拖完的样子」 | `mousedown` 时先把快照挂到 `CANVAS.drag.snap`，抬手时才 `cvPushSnapshot()` | 拖动 56,48→133,91，撤销回到 56,48；重做回 133,91 |
| 方向键微调不标脏、不入栈、刷新即丢 | 只有 `cvRender()`，没有 `cvPush/saveLayout/refreshMeta` | 一串方向键算一步：首次按键压快照，停手 500ms 落盘 + 标「未保存」 | 连按 2 次 = 1 步撤销，`dirty=true`，localStorage 里出现新坐标 |
| 每进一次画布就多挂一套 window 监听 | `bindStage()` 每次重建 DOM 都 `window.addEventListener`，旧闭包不回收 | 移到 `cvOnWindowMove/cvOnWindowUp`，用 `CANVAS._winBound` 只挂一次 | 500 节点单帧成本：首次 6.3ms，进出 8 次后仍是 6.9–9.9ms（此前会放大到 44ms / 23fps） |
| 拖动无对齐辅助线、无吸附 | 未实现（T0905 明确要求） | 比对被拖包围盒与静止节点的左/中/右、上/中/下，6 屏幕像素内吸附并画 `--guide` 竖/横线 | 拖到差 3px 时出现竖线，松手后两节点 x 完全一致，松手即清除 |
| `Ctrl+C/V` 缺失（T0905 要求） | 未实现 | 复制选中节点，粘贴时重建 id、**组内依赖一起重映射**、整体偏移 40px | 粘 2 个节点 → 7 个；`dwd_order_copy.dependsOn=[src_order_copy]`；可撤销 |
| 运维中心无导航入口 | 只注册了 `ROUTES.runbook`，`index.html` 没有对应 `nav-item` | 侧栏「总览」下补一项 | 所有 ROUTES 均有入口，点击后甘特/补数在位 |

顺带修正了辅助线的颜色：最初用 `--accent`（蓝），在满是蓝色连线的画布上会被读成一条边，改为独立 token `--guide`（暗色 `#ff7ac6` / 亮色 `#d6336c`）。

**仍然没做的（属于第四批，不在十五条范围）**：500 节点虚拟化（当前 500 节点首屏 47.9ms、拖动 6–10ms/帧，
不做虚拟化也够 60fps，但边是全量 `<path>`，节点数再上一个量级会掉）、实例列表实时推进、自助 SQL 控制台、看板卡片拖拽布局（只有「整行/半宽」和全屏）。

## 5. 缺口补齐方案（按「投入产出」排序）

### 第一批 · 可视化内核（已完成，v1.1.0）
视口模型 / 节点面板 / 属性面板 / 撤销重做 60 步 / 小地图 / 分层色 / 自动布局（见 §2.1）。
正交边与层色在本轮补齐到血缘图与执行图（§2.2）。

### 第二批 · 运行态「三次点击到细节」（已完成，v1.1.0 + v1.2.0）
画布叠加运行态、实例抽屉（参数、节点耗时、质量、日志）、实例列表筛选分页批量、节点级重跑（§2.1）；
**渲染 SQL 快照 + 本次 vs 上次**（§2.2）。

### 第三批 · 分析与设计系统（已完成，v1.1.0 + v1.2.0）
图表 hover/图例/刷选、看板筛选器与卡片宽度、设计 token、主题读变量、顶栏响应式、空状态与脏数据（§2.1 / §2.2）。

### 第四批 · 规模化与专业化（未做，按此顺序）

1. **画布 500 节点**：当前每个节点是独立 DOM + 全量重排，200 节点以上拖动会掉帧。做法：拖动时只改被拖元素（已如此），
   补「视口外节点不渲染」（虚拟化）与边用单条 `<path>` 合并；验收 = 500 节点、60fps 拖动、缩放不抖。
2. **实例列表实时事件流**：`/instances/{id}/logs/stream` 已有，列表页缺「运行中实例状态自动推进」。轮询 3s 即可，别上 SSE
   （同域连接数上限，抽屉已经因此改用游标轮询）。
3. **自助 SQL 控制台**：`SqlEditor` 目前只读。要放开必须同时给：行级策略注入、结果行数上限、超时、导出走审批、审计留痕。
   这是 BI 从 4 到 5 的唯一硬门槛。
4. **图表类型覆盖**：现在只有折线。柱/面积/饼/散点/表格五类是 Metabase 的常用面，`charts` 类型校验列表已有，缺渲染分支。
5. **dbt 对标剩余**：docs 站（模型/字段/血缘一页可读）、`--select model+` 式按上下游选择、source freshness。
6. **设计系统收尾**：pill/env-banner/gantt/diff 的语义色收成 token；做一次组件状态矩阵（default/hover/active/disabled/loading/error）
   核对，避免再出现「某个按钮 hover 变黑板」。

## 6. 验收标准（可自动执行）

```text
画布
  - 滚轮缩放后 scale 变化且节点/边同步（截图比对）
  - 20 节点 DAG 自动布局无节点重叠（矩形相交检测 = 0）
  - Ctrl+Z 可回退到上一状态（nodes 数变化）
  - 选中实例后节点出现状态色，失败节点有角标
运维
  - 单击实例 → 3 次点击内看到该节点日志与渲染 SQL
  - 渲染 SQL 的 version = 实例的 pipelineVersion（不是当前版本）
  - 「对比上次」出现左右 diff，且旧侧来自更早的实例
  - 日志抽屉打开后 ≤1s 出现首条流式日志
  - 实例列表筛选 status=failed 后行数 ≤ 总数
血缘
  - 每个节点有层色条，图例数量之和 = 节点数
  - 输入搜索词后：命中节点带 hit 类、其余 opacity=0.22
  - 双击节点后节点数 < 全图，且出现「已聚焦 xx · N 跳」；双击空白恢复全图
  - 导出 PNG 生成的 dataURL 可被 Image 解码（无异常 + toast）
  - viewBox 宽 = 元素渲染宽（无缩放）
图表
  - hover 折线出现 tooltip，含该 x 全部系列
  - 图例点击后对应 path display=none
  - 亮色主题下网格线颜色 = --line（不在 JS 里硬编码）
表结构
  - 默认渲染的表数 = 业务表数（系统表被收起）；开关展开后 = 全量
  - 系统表开关的计数与实际数量一致
设计
  - 全站 Tab 遍历 20 次，focus 元素 outline-width ≥ 2px
  - 1024×768 下顶栏按钮高度 = 30px 且单行（getClientRects().length == 1）
  - 亮色下 .topbar 按钮背景不是深色（rgb(27,34,43) 之类）
```
